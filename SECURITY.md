# Security Policy

## Supported Versions

Currently, the primary and main branch of The Algorithm is supported with security updates.

## Reporting a Vulnerability

Privacy is the core promise of this project. If you discover a security vulnerability or a privacy gap (e.g., chat data not being properly scrubbed, API keys exposed, or content written to disk), please report it immediately.

To report a vulnerability, please open an issue in this repository or contact the maintainer directly.
We will review your report, confirm the vulnerability, and issue a patch as quickly as possible.

Please do not disclose the vulnerability publicly until a fix has been released.
